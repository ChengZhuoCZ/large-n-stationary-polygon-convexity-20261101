# 项目介绍

作者：Zhuo Cheng。

单位：School of Mathematics and Statistics, HNP-LAMA, Central South University, Changsha, Hunan 410083, P. R. China。

邮箱：zhuo@outlook.cz。

本项目整理大边数条件下的非凸驻定简单多边形排除问题。以面积乘第一 Dirichlet 特征值
J(P)=A(P)λ₁(P) 为研究泛函，在删去共线冗余顶点后的有效边数 N 足够大时，研究满足
J(P)≤J(R_{N−1}) 的驻定简单 N 边形的凸性；R_k 表示单位面积正 k 边形。

归档的主结论是：存在统一 N₀，使上述低阈值驻定多边形在 N≥N₀ 时必须为凸。
证明链覆盖顶点驻定条件、边矩、近圆保形归一化、Airy 与谱扰动、Toeplitz/核比较、
正则多边形渐近，以及单反角小原子和删除步骤。
